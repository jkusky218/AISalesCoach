# AI Sales Coach 🎯🎙️

**AI-powered pre-sales flight simulator with voice role-play.**

Practice customer conversations with AI personas that push back, ask tough questions, and react realistically. Get scored and coached after every session.

Built for ServiceNow Solution Architects. Designed for any pre-sales team.

## Features

- **Voice Role-Play** — Speak your responses, hear the customer talk back
- **Realistic AI Personas** — Each with unique personality, hot buttons, and triggers
- **Instant Debrief** — Scorecard with 5 skill categories, objective tracking, and coaching tips
- **T&L Scenarios** — CSM discovery, Security (Armis/Veza), Platform expansion, Now Assist
- **Installable PWA** — Works on any phone, no app store

## Quick Start

```bash
git clone https://github.com/YOUR_USERNAME/ai-sales-coach.git
cd ai-sales-coach
npm install
npm run dev
```

Add your Claude API key to `.env`:
```
ANTHROPIC_API_KEY=your-key-here
```

## Deploy

Push to GitHub, connect to Vercel, add `ANTHROPIC_API_KEY` as an environment variable. Done.
